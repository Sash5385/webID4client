# Тренажер маршрутів і парковки (ТСЦ №8042, Київ)

Ізольована гілка з вихідним кодом тренажера (рушій на TypeScript, 3D на three.js). Не повʼязана з основним застосунком.
Збірка: `npm install`, потім `node tools/build-3d.mjs` (результат `dist/route7-3d.html`, копіюється в `public/trainer/index.html` клієнтів).
Тести: `npx vitest run`. Опис: `HANDOFF.md`.
